# PianoLens Standalone

Separate static Render app. Open index.html through HTTPS. No Android bridge, microphone, Wait Mode, relay or pairing. Reuses the existing MIDI parser, MusicEngine, geometry and piano renderer. Four self-authored MIDI fixtures are bundled. 25–150% speed, pause/resume, restart, repeat. Select opens controls and pauses; directional keys move focus. Initial release is visual playback; piano audio and personal cloud MIDI library are future work.

Service worker caches the shell/catalogue after first online visit where supported; offline operation and controls require validation on physical glasses.
